# Willen 语言 AI 开发指南

面向**编程 Agent**。假设你精通通用编程，但对 Willen 一无所知。

目标：让你**第一次就写出能跑的 Willen 代码**，而不是反复试错。

> 本指南里的每一条禁止事项和每一段示例代码，都是在真实解释器上验证过的。
> 其中大部分是编写本项目时**实际踩过的坑**。

---

## 0. 一句话定位

Willen 是**中文关键字的类 C 脚本语言**：动态类型，大括号分块，
**无闭包、无异常、无类**。

```willen
设 甲 = 1                      # 变量
常量 圆周率 = 3.14159          # 常量
如果 (甲 > 0) { 打印("正") }    # 条件——括号必须有
当 (甲 < 10) { 甲 = 甲 + 1 }    # 循环
函数 平方(x) { 返回 x * x }     # 函数
结构 点 { 横, 纵 }              # 结构体
打印("你好，{甲}！")            # 模板插值
```

## 1. 绝对禁止：写之前先看完这一节

以下每一条都是最容易犯的错误，**生成代码后逐条核对**。

### 1.1 严禁使用英文关键字

| ❌ 不要写 | ✅ 正确写法 |
|---|---|
| `if` `else` `else if` | `如果` `否则` `否则如果` |
| `for` `while` `break` `continue` | `遍历` `当` `跳出` `继续` |
| `var` `let` `const` | `设` `常量` |
| `function` `return` | `函数` `返回` |
| `struct` `class` `interface` | `结构`（**没有类**） |
| `true` `false` `null` | `真` `假` `空` |
| `and` `or` `not` | `且` `或` `非` |
| `import` `from` | 没有导入机制 |
| `//` `/* */` 注释 | `#` 注释 |

### 1.2 严禁使用全角标点

中文语境下极易输出全角符号，**以下全部非法**：

| ❌ | ✅ |
|---|---|
| `，` 全角逗号 | `,` 半角逗号 |
| `；` 全角分号 | `;` 半角分号（也可省略） |
| `（）` 全角括号 | `()` 半角括号 |
| `：` 全角冒号 | `:` 半角冒号 |
| `“”` 中文引号 | `""` 英文引号 |
| `＝` 全角等号 | `=` |

**只有字符串内容、注释、标识符里可以出现中文标点。**

### 1.3 条件必须用括号

```willen
如果 甲 > 0 { }        # ❌ 语法错误
如果 (甲 > 0) { }      # ✅

当 计数 < 10 { }       # ❌
当 (计数 < 10) { }     # ✅
```

报错长这样：

```
第 N 行：如果 的条件必须用括号包围，正确写法：如果 (条件) { ... }
```

**`遍历` 是例外**，括号可写可不写：

```willen
遍历 (元 在 数列) { }    # ✅
遍历 元 在 数列 { }      # ✅ 等价
```

### 1.4 字符串里的花括号是特殊字符（最高频错误）

`{ }` 在字符串中表示**插值**：

```willen
打印("结果是 {甲}")       # ✅ 插值：输出 甲 的值
打印("集合 {1, 2}")       # ❌ 报错：模板插值表达式未闭合
打印("集合 {{1, 2}}")     # ✅ 输出：集合 {1, 2}
打印("集合 \{1, 2\}")     # ✅ 等价写法
打印("{}")                # ❌ 报错：模板插值表达式不能为空
```

**规则**：字符串中每一个**字面**花括号都必须写成 `{{` `}}` 或 `\{` `\}`。

插值里可以放任意表达式，包括下标与字段访问：

```willen
打印("{数列[0]}")           # 合法
打印("{点甲.横}")           # 合法
打印("共 {长度(甲) + 1} 项")  # 合法
```

### 1.5 逻辑非是 `非`，不是 `!`

```willen
如果 (!真) { }        # ❌ 报错
如果 (非 真) { }      # ✅
```

`!` 只在 `!=` 里合法。

### 1.6 方法名是中文

| ❌ | ✅ |
|---|---|
| `数列.push(1)` | `数列.追加(1)` |
| `数列.pop()` | `数列.弹()` |
| `数列.length` | `数列.长度` |
| `数列.sort()` | `数列.排序()` |
| `数列.len()` | `数列.长度` |
| `文本.upper()` | `文本.大写()` |
| `文本.split(",")` | `文本.分割(",")` |
| `文本.substring(0,2)` | `文本.子串(0, 2)` |

完整清单见 §3。

### 1.7 没有闭包，没有嵌套函数定义

```willen
函数 外层() {
    函数 内层() { }     # ❌ 不支持
}
```

函数一律定义在**顶层**。而且函数体内**看不见调用者的局部变量**，
只能看见全局变量。

### 1.8 没有异常机制

没有 `try` / `catch` / `throw`。运行时错误会终止脚本并打印中文信息。
需要容错就**主动检查**（见 §4.6）。

## 2. 语义陷阱：语法对了但结果不对

### 2.1 整数除法会截断

```willen
打印(7 / 2)      # 3，不是 3.5
打印(7.0 / 2)    # 3.5
打印(7 / 2.0)    # 3.5
```

**两个整数相除，结果仍是整数。** 要小数结果，让其中一个操作数写成小数。

### 2.2 只有 `假` 和 `空` 是假

```willen
如果 (0) { }      # 会执行！0 是真
如果 ("") { }     # 会执行！空字符串是真
如果 ([]) { }     # 会执行！空数组是真
如果 (假) { }     # 不执行
如果 (空) { }     # 不执行
```

判断"非空"必须显式写：

```willen
如果 (长度(数列) > 0) { }        # ✅
如果 (数列.长度 > 0) { }         # ✅
如果 (数列) { }                  # ❌ 空数组也是真，达不到目的
```

### 2.3 数组与结构体是引用语义

```willen
设 甲 = [1, 2]
设 乙 = 甲
乙.追加(3)
打印(甲)          # [1, 2, 3]——甲也变了
```

需要独立副本，用切片复制：

```willen
设 乙 = 甲.切片(0, 甲.长度)
```

函数传参同理：函数内修改数组/结构体的**内容**会影响调用方；
但给形参本身重新赋值不影响外部。

### 2.4 字符串按字节操作

```willen
打印(长度("你好"))       # 6，不是 2（每个汉字 3 字节）
打印("你好".子串(0, 3))  # 你
打印("你好".子串(0, 2))  # 乱码——切出半个汉字
```

| 操作 | 对英文 | 对中文 |
|---|---|---|
| `长度` / `.长度` | 正确 | 返回字节数 |
| `子串` / `字符` / 下标 | 正确 | **可能切出半个汉字** |
| `查找` / `替换` / `分割` / `包含` | 正确 | **安全**（按字节匹配） |

**写中文文本处理时，优先用 `分割` 按分隔符切分，不要按位置切。**

### 2.5 小数打印最多 6 位小数

```willen
打印(1.0 / 3)      # 0.333333
打印(78.53975)     # 78.53975
打印(19.6349375)   # 19.634937（舍入到 6 位）
打印(5.0)          # 5（末尾的 .0 被去掉）
打印(1234567.0)    # 1234567（不会变科学计数法）
```

### 2.6 数组不能自动扩容

```willen
设 数列 = []
数列[0] = 1        # ❌ 报错：数组下标越界：0，长度为 0
数列.追加(1)       # ✅
```

要往数组里加东西，只能用 `追加` / `插入`。

### 2.7 常量不能重新赋值

```willen
常量 甲 = 1
甲 = 2             # ❌ 报错：不能给常量「甲」重新赋值
```

### 2.8 函数必须在使用前定义

```willen
打印(平方(3))              # ❌ 报错：未定义的函数「平方」
函数 平方(x) { 返回 x*x }
```

**把 `结构` 和 `函数` 定义放文件开头，主逻辑放最后。**

### 2.9 递归深度上限 200 层

```willen
函数 递归(甲) { 返回 递归(甲+1) }
打印(递归(0))
# 第 2 行：递归层数过深（上限 200），请检查是否存在无限递归
```

## 3. 内置库速查

### 3.1 全局函数（9 个）

| 函数 | 说明 |
|---|---|
| `打印(...)` | 输出，参数以空格分隔，自动换行 |
| `输入([提示语])` | 读一行输入，返回字符串 |
| `长度(x)` | 数组元素数 / 字符串字节数 |
| `整数(x)` | 转整数（小数截断；字符串解析失败报错） |
| `小数(x)` | 转小数 |
| `字符串(x)` | 转成打印形式 |
| `类型(x)` | 返回 `"整数"` `"小数"` `"字符串"` `"布尔"` `"空"` `"数组"` `"结构体"` |
| `随机数([下界], [上界])` | 无参：0..99；一参：上界；两参：下界、上界（**含两端**） |
| `时间()` | 毫秒时间戳 |

### 3.2 数组方法（10 个）+ 属性

| 方法 | 说明 |
|---|---|
| `.追加(元素)` | 末尾添加 |
| `.插入(位置, 元素)` | 指定位置插入，位置可等于长度 |
| `.删除(位置)` | 删除指定位置 |
| `.弹()` | 移除并返回末尾元素 |
| `.包含(元素)` | 返回布尔 |
| `.查找(元素)` | 返回下标，找不到返回 −1 |
| `.反转()` | 原地反转 |
| `.排序()` | 原地升序（全是数字或全是字符串，混合报错） |
| `.连接(分隔符)` | 各元素用分隔符连接成字符串 |
| `.切片(起, 止)` | **左闭右开**，返回新数组 |
| `.长度` | 属性，元素个数 |

### 3.3 字符串方法（9 个）+ 属性

| 方法 | 说明 |
|---|---|
| `.大写()` / `.小写()` | 仅 ASCII 字母有效 |
| `.子串(起, 止)` | 左闭右开，**按字节** |
| `.查找(内容)` | 返回字节下标，找不到 −1 |
| `.替换(旧, 新)` | 全部替换，从左到右不重叠 |
| `.分割(分隔符)` | 返回数组，分隔符不能为空 |
| `.去空白()` | 去掉首尾 ASCII 空白 |
| `.包含(内容)` | 返回布尔 |
| `.字符(下标)` | 取一个**字节** |
| `.长度` | 属性，字节数 |

## 4. 代码模板

### 4.1 标准程序骨架

```willen
# ---- 1. 结构定义放最前 ----
结构 记录 { 名称, 数值 }

# ---- 2. 然后是函数定义 ----
函数 求和(表) {
    设 合计 = 0
    遍历 (项 在 表) {
        合计 = 合计 + 项.数值
    }
    返回 合计
}

# ---- 3. 最后是主逻辑 ----
设 数据 = [记录{名称: "甲", 数值: 1}, 记录{名称: "乙", 数值: 2}]
打印("合计 {求和(数据)}")
```

### 4.2 三种循环

```willen
# 遍历数组
遍历 (元 在 数列) { 打印(元) }

# 遍历范围（含两端）
遍历 (序 在 0..9) { 打印(序) }        # 输出 0 到 9，共 10 个

# 按下标遍历
设 序 = 0
当 (序 < 长度(数列)) {
    打印(数列[序])
    序 = 序 + 1
}

# 重复固定次数
重复 3 次 { 打印("重复") }

# 提前退出与跳过
遍历 (元 在 数列) {
    如果 (元 < 0) { 继续 }      # 跳过本轮
    如果 (元 > 100) { 跳出 }    # 结束循环
}
```

### 4.3 条件

```willen
如果 (甲 > 0) {
    打印("正数")
} 否则如果 (甲 == 0) {
    打印("零")
} 否则 {
    打印("负数")
}
```

### 4.4 构建字符串

```willen
# 首选：模板插值（最简洁）
打印("姓名 {姓名}，年龄 {年龄}")

# 累加拼接
设 行 = ""
遍历 (元 在 数列) {
    行 = 行 + 字符串(元) + " "
}

# 用连接方法
打印(数列.连接(", "))
```

### 4.5 结构体

```willen
结构 学生 { 姓名, 成绩 }

设 甲 = 学生{姓名: "张三", 成绩: 85}
打印(甲.姓名)          # 张三
甲.成绩 = 90           # 修改字段
打印(甲.成绩)          # 90

# 未提供的字段默认为 空
设 乙 = 学生{姓名: "李四"}
打印(乙.成绩)          # 空

# 结构体数组
设 全班 = [学生{姓名: "张三", 成绩: 85}, 学生{姓名: "李四", 成绩: 92}]
遍历 (人 在 全班) {
    打印("{人.姓名}：{人.成绩}")
}
```

### 4.6 错误处理模式（没有异常，就主动检查）

```willen
# 安全除法
函数 安全除法(甲, 乙) {
    如果 (乙 == 0) {
        打印("除数不能为零，返回 0")
        返回 0
    }
    返回 甲 / 乙
}

# 安全取元素
函数 取元素(数列, 下标) {
    如果 (下标 < 0 或 下标 >= 长度(数列)) { 返回 空 }
    返回 数列[下标]
}

# 解析用户输入的数字（逐字节校验后再转换）
函数 解析整数(文本) {
    如果 (长度(文本) == 0) { 返回 空 }
    遍历 (字 在 文本) {
        如果 (字 < "0" 或 字 > "9") { 返回 空 }
    }
    返回 整数(文本)
}
```

### 4.7 排序（不要依赖原数组）

```willen
设 原数组 = [3, 1, 2]
设 副本 = 原数组.切片(0, 原数组.长度)    # 先复制
副本.排序()                              # 排序是原地操作
打印(副本)        # [1, 2, 3]
打印(原数组)      # [3, 1, 2]——原数组未受影响
```

### 4.8 求最大 / 最小 / 平均

```willen
函数 最大值(数列) {
    如果 (长度(数列) == 0) { 返回 空 }
    设 最大 = 数列[0]
    遍历 (元 在 数列) {
        如果 (元 > 最大) { 最大 = 元 }
    }
    返回 最大
}

函数 平均值(数列) {
    如果 (长度(数列) == 0) { 返回 0 }
    设 总和 = 0
    遍历 (元 在 数列) { 总和 = 总和 + 元 }
    返回 总和 / 长度(数列)      # 注意：整数数组会得到整数结果
}
```

### 4.9 二维数组

```willen
设 网格 = [[1, 2], [3, 4]]
打印(网格[0][1])        # 2

# 遍历二维数组
遍历 (行 在 0..长度(网格) - 1) {
    设 行文本 = ""
    遍历 (列 在 0..长度(网格[行]) - 1) {
        行文本 = 行文本 + 字符串(网格[行][列]) + " "
    }
    打印(行文本)
}

# 修改
网格[1][0] = 99
```

## 6. 写完必须验证

```bash
./willen run 你的文件.wl
```

| 退出码 | 含义 |
|---|---|
| 0 | 成功 |
| 1 | 出错，**错误信息在 stderr**，格式为 `第 N 行：<说明>` |

**报错时不要猜。** Willen 的错误信息是中文的，而且通常直接告诉你正确写法：

```
第 3 行：如果 的条件必须用括号包围，正确写法：如果 (条件) { ... }
第 5 行：模板插值表达式未闭合。字符串中的字面花括号请写成「{{」，插值表达式请写成「{表达式}」
第 7 行：结构体 点 没有字段 纵
第 9 行：数组下标越界：10，长度为 3
```

调试辅助：

```bash
./willen ast 你的文件.wl     # 打印语法树，确认优先级与结构
./willen lex 你的文件.wl     # 打印词法单元，确认分词正确
./willen repl                # 交互式试一小段代码
```

在 `repl` 里可以直接敲表达式看结果，适合快速验证某个函数的行为：

```
> 函数 平方(x) { 返回 x * x }
> 平方(7)
49
```

## 7. 完整示例：统计成绩

```willen
结构 学生 { 姓名, 成绩 }

函数 平均分(全班) {
    如果 (长度(全班) == 0) { 返回 0 }
    设 总分 = 0
    遍历 (人 在 全班) { 总分 = 总分 + 人.成绩 }
    返回 总分 / 长度(全班)
}

函数 最高分(全班) {
    如果 (长度(全班) == 0) { 返回 空 }
    设 最高 = 全班[0].成绩
    遍历 (人 在 全班) {
        如果 (人.成绩 > 最高) { 最高 = 人.成绩 }
    }
    返回 最高
}

函数 及格人数(全班) {
    设 人数 = 0
    遍历 (人 在 全班) {
        如果 (人.成绩 >= 60) { 人数 = 人数 + 1 }
    }
    返回 人数
}

设 全班 = [
    学生{姓名: "张三", 成绩: 85},
    学生{姓名: "李四", 成绩: 92},
    学生{姓名: "王五", 成绩: 45}
]

打印("班级共 {长度(全班)} 人")
打印("平均分：{平均分(全班)}")
打印("最高分：{最高分(全班)}")
打印("及格人数：{及格人数(全班)}")

遍历 (人 在 全班) {
    设 状态 = "及格"
    如果 (人.成绩 < 60) { 状态 = "不及格" }
    打印("  {人.姓名}：{人.成绩} 分（{状态}）")
}
```

输出：

```
班级共 3 人
平均分：74
最高分：92
及格人数：2
  张三：85 分（及格）
  李四：92 分（及格）
  王五：45 分（不及格）
```
