# 1. 语言概览

## 1.1 设计目标

Willen 是一门**解释型通用脚本语言**，设计目标有三条：

1. **中文关键字，但保留类 C 的骨架** —— 让不熟悉英文的人能直接读懂代码，
   同时不放弃大括号与表达式语法带来的结构清晰性。
2. **语义朴素，不设隐式陷阱** —— 不做隐式类型转换，真值判断只认两种值，
   整数除法保持整数。每条规则都能用一句话说清。
3. **对机器与人同样可读** —— 语法规则数量少、上下文无关、无歧义，
   便于编程 Agent 生成正确代码，也便于人快速上手。

## 1.2 与现存语言的差异

> 本作业要求语言"不能与现存的任何程序设计语言完全相同"。以下逐项说明。

**单项特性对照**（诚实地说，多数单项在其他语言中都出现过）：

| Willen 特性 | 相似者 | 关键差异 |
|---|---|---|
| 中文关键字 | 易语言 | 易语言用 `如果…那么…结束如果` 式的关键字闭合块；Willen 用大括号，结构更接近 C 系 |
| 范围 `0..9` | Rust、Kotlin | **Rust 的 `0..9` 是左闭右开（不含 9）**；Willen 的 `0..9` 生成闭区间数组 `[0,1,…,9]` |
| 条件必须加括号 | C、Java | Go、Rust、Swift 都**不要求**括号；Willen 强制要求，理由见 §3.4 |
| 字符串模板 `"{x}"` | Python f-string、JS 模板串 | 语法相近；Willen 在**词法阶段**完成切分，见 §3.4 |
| `遍历 (x 在 集合)` | Python `for x in …` | 关键字为中文，且括号可省略 |

**整体组合的独特性**在于以下几条同时成立，而这在任何现存语言中都找不到：

1. **`重复 N 次 { … }`** —— 关键字 `重复`、量词 `次` 与次数表达式共同构成
   一个语法单元，把表达式夹在两个关键字之间。主流通用语言中没有任何一门
   采用这种「自然语言量词式」的循环写法。
2. **`0..N` 是闭区间** —— 与 Rust/Kotlin 的同形语法语义相反。
   写 `0..9` 就是 10 个元素，与中文里「0 到 9」的直觉一致。
3. **中文关键字 + 强制括号 + 闭区间范围 + 模板插值** 四者同时存在。
4. **`否则如果` 不引入独立节点** —— 它被解析为嵌套的 `如果` 语句
   （见 §3.4），这使求值器只需实现一种条件语句。

综上：Willen 吸取了多种语言的优点，但**没有任何一门现存语言与之完全相同**。

## 1.3 一段完整的示例

```willen
# 统计一段文本的词频，并输出前几名

函数 词频统计(文本) {
    设 词表 = 文本.分割(" ")
    设 统计 = []
    遍历 (词 在 词表) {
        如果 (词 == "") { 继续 }
        设 已见 = 假
        遍历 (项 在 统计) {
            如果 (项[0] == 词) {
                项[1] = 项[1] + 1
                已见 = 真
                跳出
            }
        }
        如果 (非 已见) { 统计.追加([词, 1]) }
    }
    返回 统计
}

函数 按次数排序(统计) {
    设 结果 = 统计.切片(0, 长度(统计))
    设 轮 = 0
    当 (轮 < 长度(结果) - 1) {
        设 位 = 0
        当 (位 < 长度(结果) - 1 - 轮) {
            如果 (结果[位][1] < 结果[位+1][1]) {
                设 暂 = 结果[位]
                结果[位] = 结果[位+1]
                结果[位+1] = 暂
            }
            位 = 位 + 1
        }
        轮 = 轮 + 1
    }
    返回 结果
}

设 文本 = "苹果 香蕉 苹果 樱桃 香蕉 苹果"
设 统计 = 按次数排序(词频统计(文本))

打印("共 {长度(统计)} 个不同的词，前 3 名如下：")

设 展示数 = 3
如果 (展示数 > 长度(统计)) { 展示数 = 长度(统计) }
设 序 = 0
重复 展示数 次 {
    打印("  {统计[序][0]} 出现 {统计[序][1]} 次")
    序 = 序 + 1
}
```

输出：

```
共 3 个不同的词：
  苹果 出现 3 次
  香蕉 出现 2 次
  樱桃 出现 1 次
```

这段程序用到了：函数定义与递归调用、字符串方法、数组方法与嵌套数组、
`遍历` / `当` / `重复 N 次` 三种循环、`如果 / 否则`、`跳出` / `继续`、
模板字符串插值、结构体（`项[0]` 形式的下标访问）以及中文错误信息所依赖的
行号跟踪。

# 2. 词法规则

## 2.1 源文件与字符集

- 源文件扩展名为 `.wl`
- **编码必须是 UTF-8，且不带 BOM**。带 BOM 的文件可以工作（BOM 会被跳过），
  但推荐不带
- 若源文件不是合法 UTF-8（例如被记事本存成 GBK/ANSI），词法分析器会在
  扫描前直接报错：

  ```
  第 N 行：源文件编码不是 UTF-8，请以 UTF-8 无 BOM 格式保存
  ```

  这条检查的意义在于：GBK 编码的中文关键字字节序列不构成合法 UTF-8，
  若不拦截，用户看到的会是一连串「无法识别的字符」，无从判断真正原因。

## 2.2 注释

```
注释 = "#" { 任意非换行字符 } 换行
```

`#` 到行尾的内容被忽略。没有块注释。

```willen
# 这是注释
设 甲 = 1   # 行尾注释
```

## 2.3 标识符

```
标识符 = 首字符 { 后续字符 }
首字符 = 字母 | "_" | 任意非 ASCII 字节
后续字符 = 首字符 | 数字
```

**中文标识符与英文标识符地位完全等同**。这不是特例处理——UTF-8 中每个汉字
编码为 3 个字节，每字节都 ≥ 0x80，因此只要把规则放宽到接受非 ASCII 字节，
`斐波那契` 就会和 `fibonacci` 一样被当作一个完整的标识符读入。

合法的标识符：`甲`、`count`、`_临时`、`斐波那契`、`甲1`、`数据表`
不合法的标识符：`1甲`（数字开头）、`甲-乙`（含运算符）

## 2.4 关键字

共 21 个，**全部是中文，没有英文别名**：

| 类别 | 关键字 |
|---|---|
| 声明 | `设` `常量` `结构` `函数` |
| 分支 | `如果` `否则如果` `否则` |
| 循环 | `当` `遍历` `在` `重复` `次` `跳出` `继续` |
| 函数 | `返回` |
| 字面量 | `真` `假` `空` |
| 逻辑 | `且` `或` `非` |

**这些词不能用作变量名、函数名或字段名**。例如 `函数` 是关键字，
写 `设 函数 = 1` 会报语法错误。

## 2.5 字面量

### 整数

```
整数 = 十进制数字 { 十进制数字 }
```

64 位有符号整数，范围 −9223372036854775808 到 9223372036854775807。
超出范围时报错：`第 N 行：整数 123… 超出了可表示范围`。

负数由一元运算符 `-` 构成，**没有负数数字字面量**：`-5` 是 `(- 5)`。

### 小数

```
小数 = 十进制数字 { 十进制数字 } "." 十进制数字 { 十进制数字 }
```

小数点后**必须至少有一位数字**。`1.` 不是合法的小数字面量——它会被切成
整数 `1` 与点号 `.`。

```willen
设 甲 = 3.14     # 合法
设 乙 = 7.0      # 合法
# 设 丙 = 1.     # 不合法：1 和 .
```

### 字符串

```
字符串 = '"' { 普通字符 | 转义序列 } '"'
转义序列 = "\" ( "n" | "t" | "r" | '"' | "\" | "{" | "}" )
```

| 转义 | 含义 |
|---|---|
| `\n` | 换行 |
| `\t` | 制表 |
| `\r` | 回车 |
| `\"` | 双引号 |
| `\\` | 反斜杠 |
| `\{` | 字面左花括号 |
| `\}` | 字面右花括号 |

字符串**不能跨行**。未闭合时报 `第 N 行：字符串未闭合`。

未识别的转义序列（如 `\q`）会报错并降级为字面字符：
`第 N 行：无法识别的转义序列 '\q'`。

### 模板字符串

含有 `{表达式}` 的字符串是模板字符串：

```willen
设 名字 = "Willen"
打印("你好，{名字}！")          # 输出：你好，Willen！
打印("{1 + 2}")                  # 输出：3
```

规则：

- `{` 与 `}` 之间是**任意合法的 Willen 表达式**
- 想在字符串里写字面花括号，需写成 `{{` 与 `}}`（或 `\{` 与 `\}`）

  ```willen
  打印("{{字面}}")   # 输出：{字面}
  ```
- **只写一个 `{` 而不闭合**会报错：
  `第 N 行：模板插值表达式未闭合。字符串中的字面花括号请写成「{{」，插值表达式请写成「{表达式}」`
- 插值为空（`"{}"`）同样报错：`模板插值表达式不能为空……`
- 插值内部会跟踪括号嵌套与字符串边界，因此下面这些都合法：

  ```willen
  打印("{数列[0]}")        # 带下标，输出该元素
  打印("{点.横}")          # 带字段访问，输出该字段
  打印("{ 长度("}") }")    # 插值里含带 } 的字符串，输出 1
  ```

**求值时机**：模板在解析期被切成「文本片段 / 插值表达式 / 文本片段」的序列，
插值部分被递归送进词法+语法分析器生成子语法树。因此运行时求值模板
只剩字符串拼接，**不涉及任何字符串解析**。

### 布尔与空

```
布尔 = "真" | "假"
空   = "空"
```

## 2.6 运算符与分隔符

| 类别 | 符号 | 结合性 |
|---|---|---|
| 算术 | `+` `-` `*` `/` `%` | 左结合 |
| 比较 | `==` `!=` `<` `<=` `>` `>=` | 左结合 |
| 逻辑 | `且` `或` `非` | `且`/`或` 左结合，`非` 右结合（一元） |
| 赋值 | `=` `+=` `-=` `*=` `/=` | **右结合** |
| 范围 | `..` | 非结合（不可链式） |
| 一元负号 | `-` | 右结合 |
| 分隔符 | `(` `)` `[` `]` `{` `}` `,` `;` `:` `.` | — |

**注意**：`!` 不是运算符。逻辑非写作 `非`，单独写 `!` 会报错并提示：
`第 N 行：无法识别的字符 '!'（Willen 的逻辑非写作「非」）`

## 2.7 空白与换行

空白（空格、制表、回车、换行）仅用于分隔词法单元，**不参与语法**。
语句之间不需要分隔符——解析器通过语法结构判断语句边界。

```willen
设 甲 = 1 设 乙 = 2      # 同一行两条语句，合法
设 甲 = 1
设 乙 = 2                # 分行写，等价
```

分号 `;` 是**可选**的语句终止符，写上或省去都不影响语义。

# 3. 语法文法

## 3.1 记法

采用标准 EBNF：

| 记法 | 含义 |
|---|---|
| `=` | 定义为 |
| `,` | 连接（本文用并列表示） |
| `\|` | 择一 |
| `[ x ]` | 可选 |
| `{ x }` | 重复零次或多次 |
| `"x"` | 终结符（关键字或符号） |
| `x` | 非终结符 |

## 3.2 文法

### 程序与语句

```ebnf
程序        = { 语句 } ;

语句        = 变量声明 | 结构声明 | 函数声明 | 条件语句
            | 当循环 | 遍历循环 | 重复循环
            | 返回语句 | 跳转语句 | 块 | 表达式语句 ;

变量声明    = ( "设" | "常量" ) 标识符 "=" 表达式 [ ";" ] ;

结构声明    = "结构" 标识符 "{" [ 标识符 { "," 标识符 } ] "}" ;

函数声明    = "函数" 标识符 "(" [ 标识符 { "," 标识符 } ] ")" 块 ;

条件语句    = "如果" 条件 块
              { "否则如果" 条件 块 }
              [ "否则" 块 ] ;

条件        = "(" 表达式 ")" ;

当循环      = "当" 条件 块 ;

遍历循环    = "遍历" ( "(" 标识符 "在" 表达式 ")"
                    | 标识符 "在" 表达式 ) 块 ;

重复循环    = "重复" 表达式 "次" 块 ;

返回语句    = "返回" [ 表达式 ] [ ";" ] ;

跳转语句    = ( "跳出" | "继续" ) [ ";" ] ;

块          = "{" { 语句 } "}" ;

表达式语句  = 表达式 [ ";" ] ;
```

### 表达式（按优先级从低到高）

```ebnf
表达式      = 赋值 ;

赋值        = 或表达式 [ 赋值运算符 赋值 ] ;
赋值运算符  = "=" | "+=" | "-=" | "*=" | "/=" ;

或表达式    = 且表达式 { "或" 且表达式 } ;
且表达式    = 相等表达式 { "且" 相等表达式 } ;
相等表达式  = 比较表达式 { ( "==" | "!=" ) 比较表达式 } ;
比较表达式  = 范围表达式 { ( "<" | "<=" | ">" | ">=" ) 范围表达式 } ;
范围表达式  = 加减表达式 [ ".." 加减表达式 ] ;
加减表达式  = 乘除表达式 { ( "+" | "-" ) 乘除表达式 } ;
乘除表达式  = 一元表达式 { ( "*" | "/" | "%" ) 一元表达式 } ;
一元表达式  = ( "非" | "-" ) 一元表达式 | 后缀表达式 ;

后缀表达式  = 基本表达式 { 函数调用 | 下标访问 | 字段或方法 } ;
函数调用    = "(" [ 表达式 { "," 表达式 } ] ")" ;
下标访问    = "[" 表达式 "]" ;
字段或方法  = "." 标识符 [ "(" [ 表达式 { "," 表达式 } ] ")" ] ;
```

### 基本表达式

```ebnf
基本表达式  = 整数字面量 | 小数字面量 | 字符串字面量
            | "真" | "假" | "空"
            | 标识符 [ 结构字面量 ]
            | "(" 表达式 ")"
            | 数组字面量 ;

结构字面量  = "{" [ 字段 { "," 字段 } ] "}" ;
字段        = 标识符 ":" 表达式 ;

数组字面量  = "[" [ 表达式 { "," 表达式 } ] "]" ;
```

## 3.4 文法设计中的三个关键决定

### 一、条件的括号是强制的

`如果` 与 `当` 的条件**必须**用括号包围。这不是风格约定，而是消除歧义的必要手段：

```willen
如果 甲 { 打印(1) }      # 若允许无括号，`甲 {` 与下面的结构字面量写法完全一致
设 点甲 = 点{横: 1}      # `点{` 开始一个结构字面量
```

两者在词法层面无法区分。强制括号把这个歧义**在语法层面直接消除**，
递归下降解析器因此不需要任何回溯。

这也是 Willen 与 Go/Rust/Swift 的一个明确分歧：那三门语言不要括号，
但它们没有「标识符后紧跟花括号」的结构字面量语法。

### 二、`否则如果` 不引入独立产生式

文法里 `否则如果` 出现在 `条件语句` 的产生式中，但实现上它被解析为
**嵌套的 `如果` 语句**放进 `elseB`：

```willen
如果 (甲) { … } 否则如果 (乙) { … } 否则 { … }
```

等价于

```willen
如果 (甲) { … } 否则 { 如果 (乙) { … } 否则 { … } }
```

这样做的好处是求值器只需实现**一种**条件语句，不必为 `否则如果` 写专门分支。

### 三、`重复 N 次` 把表达式夹在关键字之间

```
重复循环 = "重复" 表达式 "次" 块 ;
```

绝大多数语言的循环语法是「关键字 + 条件 + 块」，Willen 在此处插入了
一个量词 `次`，使写法更接近自然语言。代价是解析时需要多一次 `expect(次)`，
好处是这条产生式在整个语言里独一无二。

### 补充：`遍历` 的括号是可选的

```
遍历 (元 在 数列) { … }     # 带括号
遍历 元 在 数列 { … }       # 不带括号，等价
```

这里不存在歧义——`遍历` 之后必然是「标识符 + `在` + 表达式」的固定形式，
与条件表达式无关，所以括号可选而无需担心歧义。
