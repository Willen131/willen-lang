## 五、复现步骤

```bash
# 1. 获取代码
git clone git@github.com-Willen131:Willen131/willen-lang.git
cd willen-lang

# 2. 构建
bash build.sh

# 3. 跑全部测试（一条命令）
./willen test tests/

# 4. 跑性能基准
python bench/run_bench.py

# 5. 运行应用
./willen run apps/迷宫.wl

# 6. 交互式试用
./willen repl

# 7. 验证测试集有效性（可选，约 5 分钟）
python tools/mutation_test.py
```

**环境要求**：Windows + Git Bash + g++（C++17）+ Python 3。

## 六、已知限制

如实列出，便于评估：

| 限制 | 说明 |
|---|---|
| 字符串按字节操作 | `长度("你好")` 返回 6 而非 2；`子串` 可能切出半个汉字。处理中文文本时建议用 `分割` |
| 函数调用开销较大 | 每次调用新建帧，是当前最大的性能短板（`fib` 相对 CPython 慢 9.9 倍） |
| 递归深度上限 200 层 | 超出报错。深递归场景需改用显式栈（迷宫应用即如此） |
| 无闭包、无异常、无类 | 语言设计上的有意取舍，已在规范中说明 |
| 整数溢出未检测 | 64 位有符号，超出范围会得到意外结果（已在规范中提示） |
| 中文路径依赖环境 | 构建脚本已规避，但项目路径含中文时仍建议用 Git Bash 操作 |
