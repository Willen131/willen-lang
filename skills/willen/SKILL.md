# Willen 语言

Willen 是**中文关键字的类 C 脚本语言**：动态类型、大括号分块、
**无闭包、无异常、无类**。

## 速览

```willen
结构 点 { 横, 纵 }

函数 距离平方(甲, 乙) {
    设 横差 = 甲.横 - 乙.横
    设 纵差 = 甲.纵 - 乙.纵
    返回 横差 * 横差 + 纵差 * 纵差
}

设 甲 = 点{横: 0, 纵: 0}
设 乙 = 点{横: 3, 纵: 4}
打印("距离平方 = {距离平方(甲, 乙)}")
```

## 生成代码时的硬性规则

**1. 关键字全中文**

`如果` `否则` `否则如果` `当` `遍历` `在` `重复` `次` `跳出` `继续`
`函数` `返回` `结构` `设` `常量` `真` `假` `空` `且` `或` `非`

没有 `if` / `for` / `while` / `function` / `struct` / `true` / `var` / `const`。

**2. 标点必须全半角**

禁止 `，` `；` `（）` `“”` `：` `＝`。只有字符串内容、注释、标识符里能有中文标点。

**3. 条件必须加括号**

```willen
如果 (甲 > 0) { }      # ✅
当 (计数 < 10) { }     # ✅
遍历 (元 在 数列) { }   # 括号可选，写不写都行
```

**4. 字符串里的字面花括号必须双写或转义**

```willen
打印("集合 {{1, 2}}")    # ✅ 输出：集合 {1, 2}
打印("集合 \{1, 2\}")    # ✅ 等价
打印("集合 {1, 2}")      # ❌ 报错——会被当成插值
```

插值是 `{表达式}`：`"你好，{名字}！"`、`"共 {长度(甲)} 项"`。

**5. 逻辑非是 `非`，不是 `!`**

```willen
如果 (非 真) { }    # ✅
```

**6. 方法名是中文**

`.追加()` `.插入()` `.删除()` `.弹()` `.包含()` `.查找()` `.反转()`
`.排序()` `.连接()` `.切片()` `.长度`

字符串：`.大写()` `.小写()` `.子串()` `.查找()` `.替换()` `.分割()`
`.去空白()` `.包含()` `.字符()` `.长度`

不是 `.push()` `.pop()` `.length` `.sort()` `.split()` `.upper()`。

**7. 没有嵌套函数定义**

函数一律在顶层，且**必须先定义后使用**。把 `结构` 与 `函数` 放文件开头，
主逻辑放最后。

## 语义要点

| 要点 | 说明 |
|---|---|
| **整数除法截断** | `7 / 2` 得 `3`，不是 `3.5`。要小数结果写 `7.0 / 2` |
| **只有 `假` 和 `空` 是假** | `0`、`""`、`[]` 都是真。判断非空要写 `长度(x) > 0` |
| **数组与结构体是引用语义** | `设 乙 = 甲` 后改 `乙` 会波及 `甲`；要副本用 `甲.切片(0, 甲.长度)` |
| **数组不能自动扩容** | 空数组不能用 `数列[0] = x`，要用 `数列.追加(x)` |
| **字符串按字节** | `长度("你好")` 是 `6` 不是 `2`；`子串`/下标按字节切 |
| **`0..9` 含 9** | 闭区间，共 10 个元素 |
| **递归上限 200 层** | 超出报中文错误，不会崩溃 |

## 运算符

| 类别 | 运算符 | 结合性 |
|---|---|---|
| 算术 | `+` `-` `*` `/` `%` | 左结合 |
| 比较 | `==` `!=` `<` `<=` `>` `>=` | 左结合 |
| 逻辑 | `且` `或` `非` | `且`/`或` 左结合；`非` 是一元 |
| 赋值 | `=` `+=` `-=` `*=` `/=` | **右结合** |
| 范围 | `..` | 非结合 |
| 一元负号 | `-` | 右结合 |

**优先级从低到高**：赋值 → `或` → `且` → `==` `!=` → `<` `<=` `>` `>=`
→ `..` → `+` `-` → `*` `/` `%` → 一元 → 后缀

无歧义时不必加括号，**但拿不准就加**——加了总不会错。
例如 `0..行数 - 1` 会被解析为 `0..(行数 - 1)`，因为 `..` 优先级低于 `-`。

## 作用域

- **顶层 `设` / `常量` 声明的变量是全局的，函数内可读也可写**
- 函数内的 `设` 创建**局部变量**，不会影响同名的全局变量
- `{ }` 是块级作用域：块内 `设` 的变量出了块就没了
- 循环体每轮重新执行，因此循环内 `设` 的变量每轮都是新的，不会「重复声明」

```willen
设 计数 = 0
函数 加一() { 计数 = 计数 + 1 }      # ✅ 直接改全局变量
加一()
打印(计数)                           # 1

函数 遮蔽() {
    设 计数 = 99                     # 这是局部变量
    返回 计数
}
打印(遮蔽())                         # 99
打印(计数)                           # 1——全局未被影响
```

## 类型与数值范围

| 类型 | 说明 |
|---|---|
| 整数 | **64 位有符号**（约 ±9.2×10¹⁸） |
| 小数 | 双精度浮点，打印时最多 6 位小数 |
| 字符串 | UTF-8 字节序列，**按字节操作** |
| 布尔 | 只有 `真` / `假` |
| 空 | 表示「没有值」 |
| 数组 | 元素可为任意类型，**引用语义** |
| 结构体 | 具名字段，**引用语义** |

`类型(x)` 返回上述类型名。**整数运算不自动提升为小数**——
两个整数相乘不会因为结果大就变成小数，超出 64 位范围会得到意外结果。

## 字符串拼接

`+` 可以拼接字符串，任一侧是字符串即可：

```willen
打印("共 " + 3 + " 项")     # 共 3 项
打印(3 + "项")              # 3项

设 行 = ""
遍历 (元 在 数列) { 行 = 行 + 字符串(元) + " " }
```

也可以用模板插值，通常更简洁：`"共 {3} 项"`。

## 内置库

**全局函数**：`打印` `输入` `长度` `整数` `小数` `字符串` `类型` `随机数` `时间`

**数组方法**：`追加` `插入` `删除` `弹` `包含` `查找` `反转` `排序` `连接` `切片`
（`切片` 左闭右开；`.长度` 是属性）

**字符串方法**：`大写` `小写` `子串` `查找` `替换` `分割` `去空白` `包含` `字符`
（`.长度` 是属性）

`随机数(下界, 上界)` 含两端；无参时是 `0..99`。

## 常用模板

```willen
# 条件
如果 (甲 > 0) {
    打印("正数")
} 否则如果 (甲 == 0) {
    打印("零")
} 否则 {
    打印("负数")
}

# 三种循环
遍历 (元 在 数列) { 打印(元) }
遍历 (序 在 0..9) { 打印(序) }
当 (条件) { }
重复 3 次 { 打印("重复") }

# 提前退出
遍历 (元 在 数列) {
    如果 (元 < 0) { 继续 }
    如果 (元 > 100) { 跳出 }
}

# 安全排序（保留原数组）
设 副本 = 原数组.切片(0, 原数组.长度)
副本.排序()

# 求最大
函数 最大值(数列) {
    如果 (长度(数列) == 0) { 返回 空 }
    设 最大 = 数列[0]
    遍历 (元 在 数列) {
        如果 (元 > 最大) { 最大 = 元 }
    }
    返回 最大
}
```

## 写完后必须运行

```bash
./willen run 你的文件.wl
```

退出码非 0 时看 **stderr** 的中文错误信息，格式 `第 N 行：<说明>`，
通常直接说明了正确写法：

```
第 3 行：如果 的条件必须用括号包围，正确写法：如果 (条件) { ... }
第 5 行：模板插值表达式未闭合。字符串中的字面花括号请写成「{{」，插值表达式请写成「{表达式}」
第 7 行：结构体 点 没有字段 纵
```

调试辅助：

```bash
./willen ast 文件.wl     # 打印语法树
./willen lex 文件.wl     # 打印词法单元
./willen repl            # 交互式试代码
```
