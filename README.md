# Willen 语言

一门**中文关键字**的解释型脚本语言，及其解释器的完整实现。

程序设计实践课程大作业 · 作者：Willen131

---

## 语言特色

| 特色 | 示例 |
|---|---|
| 中文关键字 | `设` `常量` `如果` `否则` `当` `遍历` `重复 5 次` `函数` `返回` `结构` |
| 类 C 骨架 | 大括号分块，分号可选 |
| 字符串模板 | `"你好，{名字}！共 {长度(数列)} 项"` |
| 范围语法 | `0..9` 直接生成数组，无需手写循环 |
| 结构体 | `结构 点 { 横, 纵 }` → `点{横: 3, 纵: 4}` |
| 中文错误提示 | `第 3 行：除数不能为零` |

### 一段完整的 Willen 程序

```willen
函数 斐波那契(甲) {
    如果 (甲 < 2) { 返回 甲 }
    返回 斐波那契(甲-1) + 斐波那契(甲-2)
}

设 名字 = "Willen"
遍历 (序 在 0..9) {
    打印("{名字} 的第 {序} 项：{斐波那契(序)}")
}
```

## 构建

依赖：`g++`（需支持 C++17）与 Git Bash。

```bash
bash build.sh
```

产物是单个 `willen.exe`，已静态链接，不依赖任何运行库 DLL，可直接拷贝到其它机器运行。

## 使用

```bash
./willen run  <文件.wl>     # 运行脚本
./willen lex  <文件.wl>     # 打印词法单元序列（调试用）
./willen test <目录>        # 运行黑盒测试集，一条命令跑完全部测试
./willen repl               # 交互式解释器
```

> 源文件必须保存为 **UTF-8 无 BOM** 编码。用记事本另存为 ANSI/GBK 会导致中文关键字无法识别。

## 代码怎么读

解释器的数据流只有一条线，按这个顺序读即可：

```
源码 .wl
   ↓  lexer.cpp      把文本切成词法单元（Token）
词法单元序列
   ↓  parser.cpp     递归下降，组装成语法树（AST）
AST
   ↓  interp.cpp     遍历语法树求值
运行结果
```

每个 `.cpp` 文件都只做一件事，且不超过 500 行。建议从 `lexer.cpp` 开始——
中文关键字能工作，全靠它把标识符规则放宽到接受非 ASCII 字节。
